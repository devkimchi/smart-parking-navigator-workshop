# Security Policy

## Reporting a Vulnerability

Do not open a public GitHub issue for a security vulnerability.

Report vulnerabilities privately to **security (at) devkimchi (dot) com** and include:

- A description of the vulnerability
- Steps to reproduce it
- The potential impact
- A suggested remediation, if available

You will receive an acknowledgment within 48 hours. We will coordinate
investigation, remediation, and disclosure with the reporter.

## Supported Versions

Until the first release, security fixes are applied to the default branch.
After versioned releases begin, this section will identify the supported
release lines.

## Disclosure

When a vulnerability is confirmed, maintainers will develop and test a fix,
publish a patched release and security advisory, and credit the reporter unless
anonymity is requested.
